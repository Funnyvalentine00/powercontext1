# 示例语料说明

这里的 6 篇文档是**为验证样例自造的示例语料**，不是真实论文，其中的实验数字均为示例值。

它们围绕同一个研究方向（「嵌入式数据库里文档检索的延迟优化」）编写，
目的是让「证据边界」功能可以被稳定演示：

- 有些子问题在语料里有充分证据（多篇文献交叉支持）；
- 有些子问题在语料里证据稀少或完全没有，会被如实标成「证据缺口」。

替换成你自己的真实文献：把 PDF 转成 Markdown（或直接放 `.md` / `.txt`），
放进这个目录，然后执行 `rca ingest data/corpus` 即可。语料内容不参与评分，
评审看的是检索、引用可核验和状态复用是否真的工作。
